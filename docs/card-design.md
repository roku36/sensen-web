# カード設計 — 種類のタクソノミーと拡張計画

このゲームのカードプール (src/sim/cards.ts) は Slay the Spire 移植が出発点で、
87定義のうち相当数が「数値違いのクローン」になっている。原作でのカードの個性
(怒り=捨て札連携、武装=アップグレード、歩哨=エナジー回収) は、このゲームに
該当システムがないため脱落し、裸の数値だけが残ったからだ。

さらに重大な欠落: **烈閃・連閃・休息・焦土という固有の時間機構を参照する
カードが1枚も存在しない**。地形 (烈閃タイムライン) や リズム (連閃・休息) は
システムとして実装済みなのに、デッキ構築がそれに触れられない。戦略性の
伸びしろはここにある。

関連: [game-design.md](./game-design.md) のスキル4軸 / [design-language.md](./design-language.md)

---

## 1. 設計原則 (カードの法)

1. **1カード = 1判断。** そのカードを手にしたとき固有の問いが生まれないなら
   存在価値がない。判定法 (クローンテスト): 2枚のカードの数値を入れ替えても
   プレイ判断が変わらないなら、片方は削る。
2. **すべての種類は時間と取引する。** 各種類は名前のついた時間機構
   (閃・積み・熟成・烈閃・連閃・休息・焦土) のどれかに固有の判断で接続する。
   時間に触れないカードは「数値」であって「カード」ではない。
3. **既存の法を守る。** 整数演算のみ / 予約は失敗しない / 相手の予約済み
   プランには干渉しない (情報・地形・自分の行動だけが武器)。
4. **強いタイミング効果には開示の対価。** 烈閃や積みに賭ける高倍率カードは
   [開示] で相手に読まれる。読まれてなお通すのが技術。

## 2. カードの種類 (9 + 状態)

各種類は「生む判断」と「鍛えるスキル軸」で定義する。数値は種類を定義しない。

| 種類 | 機構 | 生む判断 | スキル軸 |
|---|---|---|---|
| **刃** 基本攻撃 | 閃・連閃の燃料 | いつ撃つか、チェーンのどこに置くか | テンポ所有 |
| **盾** 受け | ブロック減衰 | 相手の解決にどれだけ近づけて張るか | 読み |
| **重** 積み | 積み閃・[開示] | 公開した山をどの閃に着地させるか | コミットの呼吸・精密 |
| **熟** 熟成 | 熟成/変質・枠占有 | 待つか使うか、腐る前の使用窓 | コミットの呼吸 |
| **賭** 烈閃連動 | 烈閃 (公開地形) | 地形に賭けるか平地で妥協するか | 精密合わせ |
| **律** 連閃連動 | 連閃 (±のリズム) | チェーンを伸ばすか、ここで収穫するか | テンポ所有・コミット |
| **休** 休息連動 | 休息 (既定行動) | 休む閃を「弱い閃」から「仕込みの閃」に | 読み・コミット |
| **転** 資源変換 | HP↔カード↔時間 | リスクの価格付け | テンポ所有 |
| **構** 永続 | 試合全体 | テンポを捨てて長期に投資するか | コミットの呼吸 |
| **拍** 同境界反応 | 完全対称グリッド | 相手の解決境界を1閃前に読み切れるか | 読み・精密合わせ |
| 状態 | — | (ジャンク。判断は「いかに掴まされないか」) | — |

**賭・律・休・拍は新種類** (効果kindの新設が必要)。刃〜構は既存メカニクスの
整理で成立する。

### 各種類の規範 (どう作り、どう作らないか)

- **刃**: プールの過半を占めてよいが、全員が異なる問いを持つこと。
  現存で生き残る問い — 打撃(基準値)・二連撃/連打(ブロックに弱い分割)・
  鉄の波動(攻防一体)・柄打ち(補充内蔵=連閃減衰の回避)・血操術(HP前借り)・
  体当たり(ブロックの二重利用)・強打/ラリアット(状態付与)。
  **純粋なNダメージは打撃1枚で十分** — 怒り・薙ぎ払い・猛攻・頭突き・
  灼熱の一撃はクローンテストで死ぬ。
- **盾**: 同じくブロックNのクローン (武装・歩哨・不屈・幽霊鎧) は防御に統合。
  生き残る問い — 受け流し(補充内蔵)・塹壕(倍化=張りタイミング倍率)・
  炎の障壁(反撃)・鉄壁(積み盾=防御の予告)。
- **重**: 現行 (殺戮/重撃/鬼火/破城/血の宴…) は健全。種類として完成済み。
  新規追加は賭との複合 (下記・天槌) のみ。
- **熟**: 業火の種・鉄の蕾の2系統で問いは確立済み。3系統目は当面不要
  (種類の証明は済んでいる。量産は薄める)。
- **賭**: 効果は「烈閃中に解決したら+X」。全攻撃が烈閃で+4を得る既存
  ルールの**レバレッジ版**であり、デッキ構築で地形読みへの投資量を選べる
  ようにする。外したときに弱いことが対価。
- **律**: 効果は「連閃に比例 / 連閃N以上で追加」。1枚ドロー経済では
  ドロー=連閃−1なので、「いつ補充を差し込むか」の判断がこの種類の
  収穫タイミングと直結する。
- **休**: 休息は無操作の既定行動だが、これを**選んで**使う理由を作る。
  焦土第1段階の相殺 (回復1=ダメージ1) と組むと防衛戦略の軸になる。
- **転**: 血操術・瀉血・供物・捕食・死神で確立済み。破裂 (自傷→筋力) が
  エンジンとして機能。現状維持。
- **拍 (パリィ)**: 完全対称化 (両者が同一の閃グリッドを共有、2026-06) で
  開いた種類。「この札の解決と同一の閃境界に相手の攻撃が解決したら〜」
  という条件効果。反射神経は一切不要 — 解決境界は1閃以上前にコミット
  するので、相手の公開情報 (キュー・開示済み重カード・烈閃地形) から
  解決閃を**読み切る**技術がすべて。外せばただの弱いカード、当てれば
  大きい。読み合いの頂点であり、乱発されると膠着するので枚数は絞る。
  例:「見切り」スキル1閃 — ブロック4。同境界に相手の攻撃が解決したら
  ブロック12。/「燕返し」攻撃1閃 — 5ダメージ。同境界に相手の攻撃が
  解決したら+10。(相手の予約・行動には一切干渉しない — 法3を守る)
- **構**: 8枚程度の精鋭に絞る。各々が異なる試合計画を提示すること
  (金属化=時間を防御に / 燃焼=時間を削りに / 悪魔の姿=時間を筋力に /
  防壁=減衰の法則自体を買う / 巨獣=防御を攻撃に / 残虐=HPを補充に)。

## 3. 新カード第1弾 (賭・律・休の証明)

種類ごとに2枚 — 1枚は軽く読みやすく、1枚は重くレバレッジが効く。

### 賭 (烈閃連動) — 新効果: `surgeBonus`
| カード | 種別 | コスト | 効果 |
|---|---|---|---|
| 雷乗り | 攻撃 | 1閃 | 7ダメージ。烈閃中に解決なら+9 (計16+全体ボーナス4)。 |
| 天槌 | 攻撃 | 2閃・積み1閃 [開示] | 14ダメージ。烈閃中に解決なら+14。 |

天槌は積み+開示なので、相手は「次の烈閃に28が来る」と読める — 読まれてなお
合わせ切るのが精密軸の頂点。雷乗りは軽いので予約調整で合わせやすいが上振れも小さい。

### 律 (連閃連動) — 新効果: `renzanScale` / `renzanThreshold`
| カード | 種別 | コスト | 効果 |
|---|---|---|---|
| 追い打ち | 攻撃 | 1閃 | 4ダメージ + 連閃×2 (連閃ボーナスと別枠、最大4+10)。 |
| 残心 | スキル | 1閃 | ブロック3 + 連閃×2。 |

追い打ちはチェーン終端の「収穫」カード。残心は攻めながら受ける選択肢 —
チェーンを守りに変換するが、スキル解決も連閃を進めるので攻めに戻れる。

### 休 (休息連動) — 新効果: `restBoost` (パワー) / `afterRest` (条件)
| カード | 種別 | コスト | 効果 |
|---|---|---|---|
| 深息 | パワー | 1閃 | 以後、休息の回復+2 (計3)。 |
| 明鏡 | スキル | 1閃 | ブロック6。直前の解決が休息なら+8 (計14)。 |

深息は焦土戦を見据えた長期投資 (第2段階のダメージ2も相殺する)。明鏡は
「休んでから受ける」という呼吸をリズムとして成立させる。

### 数値の根拠
- 雷乗りの期待値: 烈閃は公開かつ予約で合わせられるため的中率は技術依存。
  半分当てれば 7+ (9+4)/2 ≈ 13.5/閃 で打撃(6+連閃)よりやや上、毎回外せば下。
- 追い打ち: 連閃3で10ダメージ=強打相当。連閃5 (上限) で14。チェーン構築の
  报酬として妥当で、ドロー減衰 (−1) の機会費用を可視化する。
- いずれも整数のみ・烈閃の全体+4とは加算で重複 (乗算なし)。

## 4. クローン整理 (削除候補)

クローンテストで死ぬ定義。**削除はPhase 3** (デッキ保存・ドラフトプール・
パズル・AIヒューリスティクスへの波及があるため新種類の検証後に一括で):

- 攻撃: 怒り(=打撃) / 薙ぎ払い・猛攻(=8ダメ) / 頭突き(=9ダメ) /
  灼熱の一撃(=12ダメ) / 無謀な突進(=蛮撃の下位) / 旋風(=剣のブーメラン+α) /
  ドロップキック(=柄打ちの下位)
- スキル: 武装・歩哨(=防御) / 不屈・幽霊鎧(≈防御+α) / 撹乱・二段撃ち(=1ドロー) /
  焦熱の契約・地獄の刃・発掘・鬨の声(=2ドロー、1枚に統合) / 弱点看破(=誇示+1) /
  威嚇(=武装解除の下位、どちらか1枚)
- パワー: 進化・火炎放射 (状態カード参照はトリガー源が細すぎる。様子見)

約15定義の削減 → プールは「全員が固有の問いを持つ」約60枚の精鋭になる。

## 5. 実装フェーズ

**Phase 1 — 新種類の実装 (賭・律・休、6枚)**
1. effects に `surgeBonus` / `renzanScale` / `restBoost` / `afterRest` を追加
   (解決時点の烈閃判定は events.ts の公開タイムライン参照、連閃値・直前解決
   種別は PlayerState から整数で取得)
2. checksum / predict (確定マーカーのダメージ予測には賭の条件値は含めない —
   予測は最小保証値で表示) / UI カード表記
3. 検証ハーネス: mature-balance.test.ts と同型の per-種類テスト —
   「機構を理解する戦略 ≥ 素朴プレイ」かつ「勝率0.3〜0.85帯」を賭・律・休
   それぞれで証明。これが「判断が実在する」ことの計測的証拠
4. パズル1問追加 (烈閃合わせ: 天槌を第N閃の烈閃に着地させる)

**Phase 2 — AI対応**
- lv4 (ロールアウト) は評価関数変更なしで新カードを自然に扱える (検証のみ)
- lv3 に賭カードの烈閃合わせ加点 (既存の烈閃整合ロジックを流用)
- issue #7 (lv2/lv3 の1枚ドロー経済再調整) とまとめて再計測、skip解除

**Phase 3 — クローン整理**
- §4 の削除 + deck-storage の旧ID移行マップ + ドラフトプール/標準デッキ/
  パズル更新。全テスト・ラボ100戦で歪みがないこと

各フェーズの合格条件: 全テスト緑 / パズル全問「想定解クリア+放置不可」/
ラダー (現行2テスト+lv4系) 維持 / 新種類ハーネスの帯域内。
