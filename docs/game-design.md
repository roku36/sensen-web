# sensen ゲームデザインノート — スキルの所在

## スキルモデル

このゲームのプレイスキルは反射神経ではなく、以下の4軸に置く:

1. **テンポの所有** — 時間 (閃) は唯一の資源。いつ引き、いつ撃ち、いつ待つか。
   その全てがプレイヤーの意思決定であること
2. **読み** — 相手の公開キュー (確定済みの未来) から着弾時刻を読み、
   ブロックを減衰込みでジャストに合わせる
3. **コミットの呼吸** — 予約 (秘匿・可逆) と確定 (公開・不可逆) の往復。
   早いコミット = 連閃の勢い、遅いコミット = 柔軟性と情報秘匿
4. **精密合わせ** — 烈閃への解決着地、重カードの原子発火、熟成の使用窓

## 決定: 強制オートパイロットの廃止 (2026-06)

旧仕様: キューと予約が空になると、シムが自動でドロー or 左端カードを
発動していた (「プレイヤーを暇にさせない」ため)。

**廃止理由 — 怠惰の自動補正はスキル差を圧縮する:**

- 無操作のプレイヤーでもカードが回り、下手な操作との差が消える
- 「何もしない」が選択肢でないなら、テンポの所有 (軸1) は半分しか
  プレイヤーのものでない
- キューを空に保つ = 手の内を見せない、というブラフ (軸3) が
  オートパイロットの存在によって構造的に不可能だった
- 膠着の防止は焦土 (第30閃〜) が既に担っており、存在理由が消滅していた
- 予測グラフは当初から predictMode でオートパイロットを除外しており、
  シムと予測の意味論が食い違っていた (廃止で一致する)

**帰結:**

- 無操作 = 時間だけが流れる。失ったテンポは相手の圧力と焦土が回収する
- predictMode フラグは不要になり削除 (シム = 予測)
- AI 各レベルは元々能動的に行動しており影響は軽微。ロールアウト内の
  「無入力の未来」が真の無行動になり、Lv4 の評価がより正確になる
- パズルの「放置では解けない」保証はより強い意味を持つ
