# sensen 設計言語 — 「居合」

> 長い静止と、一瞬の閃き。タイムラインは刃の軌跡である。

AI slop（紫グラデーション・一様なグロー・全要素角丸・装飾の均等塗布）を排し、
ゲームの主題に根ざした明示的な制約で全画面を統一する。

## 色 — 厳格に3系統のみ

| トークン | 値 | 用途 |
|---|---|---|
| 墨 (sumi) | `#0f0f11` 地 / `#17171a` 面 / `#222226` 界線面 | 背景・パネル。**紫味禁止** |
| 紙 (kami) | `#e8e4da` 主文字 / 40%〜12% で階調 | テキスト・罫線 (hairline 1px) |
| **朱 (shu)** | `#e8472b` | **時間と意思の刃**: NOWライン・予約・確定・烈閃・リーサル。これ以外に使わない |

機能色（ゲームプレイ上の識別、テーマ色ではない・彩度を落とした flat）:
- 攻撃 = 弁柄 `#8e3a30` / 技 = 藍鉄 `#33526e` / パワー = 紫紺 `#544668` / 状態 = `#3a3a3e`
- ブロック帯: 相手 = 藍鉄系、自分 = 青磁系。毒 = 苔。いずれも flat + 1px 縁

**禁止**: グラデーション背景、金色、グロー(box-shadowの発光)、紫アクセント。

## 形 — 刃

- 角丸は 0〜2px。カード・パネルは**直角**、刃のように鋭く
- モチーフはひとつ: **斜め切り** — カード左上のコスト領域を 45° で切り落とす
  (clip-path)。適用箇所はコスト札と NOW チップのみ。乱用しない
- 深度は hairline (1px, 紙12%) で表現。影は浮遊要素 (tooltip/overlay) の1段のみ

## 文字

- 見出し・閃数値: **明朝** (`"Hiragino Mincho ProN", "Yu Mincho", serif`)。
  ウェイトは極端に — 800 か 300、中間を使わない
- 本文・説明: system sans (可読性優先)。数値カウンタ: ui-monospace
- 字間: 見出しは広く (letterSpacing 4+)、ラベルは 1〜2

## 動き — 一閃のみ

- 環境アニメーションループ (shimmer / pulse / breathing glow) は**全廃**
- 動いてよいのは**出来事**だけ: HP変化の数字ポップ、カード解決の白閃 (0.4秒)、
  ホバーの 2px 浮き
- タイムラインのスクロールそのものが本作最大のモーションである。飾らない

## 検証規律

- 変更ごとにスクリーンショットで「朱が3箇所以上に散っていないか」
  「グラデーション/グローが紛れ込んでいないか」を確認する
- perf-check のフレームペーシングを劣化させない
